# Sistema de Gestión MeztliTech - Prácticas de Ingeniería

Este repositorio contiene las prácticas de desarrollo web realizadas en el **Tecnológico de Estudios Superiores de Villa Guerrero (TESVG)**.

## 🚀 Contenido de las Prácticas
* **Práctica 1-2:** Marcado estructural, títulos, párrafos y codificación de caracteres.
* **Práctica 3:** Implementación de **Listas** (ordenadas y desordenadas) y **Enlaces** (internos, externos y mailto).
* **Diseño:** Uso de **Bootstrap 5** y CSS personalizado para la interfaz de usuario.
* **Backend:** Conexión a bases de datos **PostgreSQL** y **MySQL** mediante PHP (PDO).

## 🛠️ Tecnologías Utilizadas
* **Lenguajes:** HTML5, CSS3, PHP.
* **Base de Datos:** PostgreSQL / MySQL.
* **Servidor:** Debian (Linux) vía SSH.
* **Control de Versiones:** Git & GitHub.

## 📁 Estructura del Proyecto
* `index.html`: Página principal con el formulario y recursos.
* `mis_estilos.css`: Estilos personalizados.
* `db-pgsql.php`: Configuración de la conexión a base de datos.
* `usuarios.php`: Lógica para procesar el registro.
